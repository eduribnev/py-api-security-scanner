## [1.0.0] - 2026-10-20

### Added

- OpenAPI JSON specification support.
- OpenAPI YAML specification support.
- OpenAPI-driven endpoint discovery.
- Security header scanning.
- OpenAPI-driven security header scanning.
- BOLA candidate discovery from OpenAPI specifications.
- Assessment planning for BOLA candidates.
- HTML report generation.
- JSON report generation.
- Markdown report generation.
- GitHub Actions CI workflow.
- Project status and architecture documentation.
- Support for OpenAPI candidate and assessment-plan reporting.

### Improved

- Professional README structure.
- Documentation clarity around BOLA candidates and assessment plans.
- Report consistency across HTML, JSON, and Markdown outputs.
- OpenAPI parsing architecture and workflow documentation.

### Security Notes

- BOLA candidates are informational and do not represent confirmed vulnerabilities.
- Assessment plans are informational and do not execute authorization tests.
- Scanner usage is intended only for authorized environments.
